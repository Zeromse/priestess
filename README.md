# 普瑞赛斯在哪儿？｜PRIESTESS 影像档案

基于参考视频《普瑞赛斯在哪儿？◇.mp4》制作的交互式展示网站。网站将视频中的人物剪影、菱形标记、研究手稿、空间应用和终端画面整理为可浏览的影像档案，并提供视觉解构与终端操作演示。

使用原生 **HTML + CSS + JavaScript**，无需安装前端依赖、无需构建，支持离线打开。

## 快速开始

### 方式一：直接打开

解压完整代码包，双击 `index.html`，或将其拖入浏览器。

请保留 `index.html`、`styles.css`、`app.js` 和 `assets/` 的相对位置。图片、视频、图标和样式均随项目提供，不依赖外部 CDN。

### 方式二：Windows 一键预览

双击 `start-preview.cmd`。脚本会启动本地服务，并在默认浏览器中打开：

<http://localhost:4177>

启动脚本优先使用已安装的 Node.js；未找到时，会尝试当前用户目录中的 Codex 内置 Node.js。两者都不可用时，可使用上面的直接打开方式。

在启动服务的窗口按 `Ctrl+C`，或关闭该窗口，即可结束预览。

### 方式三：命令行预览

在项目目录中运行：

```sh
node server.cjs
```

需要同时打开浏览器时运行：

```sh
node server.cjs --open
```

如果默认端口被占用，可在 PowerShell 中指定其他端口：

```powershell
$env:PORT = 4178
node server.cjs
```

然后访问 <http://localhost:4178>。本地服务仅监听 `127.0.0.1`，供当前电脑访问。

## 页面结构与功能

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 总览 | 主题标题、原视频画面、项目关键词 | 进入档案、播放原片、导航跳转 |
| 影像档案 | 从原片提取的六个切片 | 分类筛选、完整画面弹窗、前后帧切换、播放对应片段 |
| 视觉解构 | 几何构成、黑白对比、材质表达 | 标签切换、辅助网格开关、标记比例调节 |
| 交互终端 | 频率校准与记忆片段 | 调节目标、执行校准、查看完成反馈、读取记忆、复位 |
| 页尾 | 来源说明与快捷操作 | 重新观看、动效开关、返回顶部 |

### 影像档案与播放器

- 档案可按「标识与意象」「研究与空间」「终端与载体」筛选。
- 点击卡片可查看完整竖屏画面、说明和原片时间。
- 前后帧浏览限定在当前筛选结果内；到达边界时，相应按钮禁用。
- 视频弹窗支持原生播放控制、章节跳转和时间轴定位。
- 拖动时间轴时暂停播放，便于查看指定时刻；关闭视频弹窗时停止播放。

### 终端演示

- 初始读数为 **83.67%**，取自参考影像。
- 拖动滑块可在 `0–100%` 之间设定目标，并同步更新读数、进度条与波形透明度。
- 点击「开始校准」后，读数以动画变化到所设目标；校准期间目标滑块与校准按钮禁用。
- 点击「重置」可取消当前校准并恢复初始读数。
- 「记忆片段」展示原片中的「我会有自己的选择。」；读取后可复位。

终端没有连接后台。校准结果、状态与波形用于交互演示，不表示真实测量或业务数据。

```text
priestess-ui/

├── styles.css          # 色彩、排版、响应式布局、组件状态与动效

├── assets/
│   ├── reference.mp4   # 原始参考视频副本
│   └── *.jpg           # 从视频提取的画面素材

└── README.md           # 本说明文件
```

工作目录中的 `reference/` 保存制作时的预览帧等辅助资料，不是网站运行必需内容，也不包含在交付代码包中。部分素材文件名沿用了制作阶段的命名，画面含义以页面说明与实际图片为准。

## 修改网站

### 修改文案与档案

编辑 `index.html` 中的标题、段落、卡片和章节按钮。

档案卡片通过以下属性向交互脚本提供内容：

| 属性 | 用途 |
| --- | --- |
| `data-category` | 分类：`identity`、`research` 或 `interface` |
| `data-title` | 详情弹窗标题 |
| `data-description` | 详情说明 |
| `data-time` | 视频定位时间，单位为秒 |
| `data-image` | 完整画面的相对路径 |

新增卡片时，保留 `.archive-card` 类名及上述属性，并设置图片替代文字。若改变档案总数，请同步更新页面中的「六个切片」、`06` 等固定文案；脚本会在筛选时计算可见卡片数量。

### 替换素材

将图片或视频放入 `assets/`，然后更新 HTML 中对应的 `src`、`poster` 和 `data-image`。

替换视频时，应同时检查卡片的 `data-time`、播放器章节的 `data-chapter`、可见时间标签，以及 `app.js` 中元数据加载前使用的默认时长 `9.98`。播放器加载后会读取实际视频时长。

### 修改样式

`styles.css` 顶部的 `:root` 定义主要色彩与字体：

```css
:root {
  --bg: #111310;       /* 深色背景 */
  --ink: #f1f2e9;      /* 主要文字 */
  --accent: #e7ff79;   /* 荧光黄强调色 */
  --paper: #f0f1e9;    /* 浅色展示区 */
}
```

样式包含桌面、平板和手机布局，以及页面末尾的阅读层级调整规则。修改某个字号或组件时，需留意后续媒体查询与覆盖规则。

### 修改交互

编辑 `app.js`。页面元素通过 ID、类名和 `data-*` 属性与脚本关联，修改这些标识时需要同步调整两处。脚本无需网络请求，不使用数据库或浏览器存储；刷新页面会恢复初始交互状态。

## 键盘与动效

- 使用 `Tab` / `Shift+Tab` 在链接、按钮、滑块等控件之间移动。
- 使用 `Enter` 或空格激活按钮。
- 在标签页上使用方向键切换，`Home` / `End` 跳到首尾标签。
- 在画面详情中使用左右方向键浏览前后帧。
- 使用 `Esc` 关闭弹窗或已展开的手机导航。
- 页面提供「跳到影像档案」快捷链接、焦点样式和状态反馈。
- 页尾可关闭动效；页面也响应系统的「减少动态效果」设置。

## 静态托管

网站运行只需要以下内容，保持相对目录结构即可：

```text
index.html
styles.css
app.js
assets/
```

不需要执行构建命令，也不需要将本地预览服务部署到线上。静态服务器应正确提供 MP4 文件；支持 HTTP Range 请求有助于视频定位与分段读取。随附的 `server.cjs` 已支持本地视频分段读取。

## 常见问题

**页面没有样式或图片未显示**

先完整解压代码包，再打开 `index.html`。确认 `styles.css`、`app.js` 和 `assets/` 没有移动或改名。

**点击控件没有反应**

确认浏览器允许 JavaScript，并使用支持原生 `<dialog>`、CSS Grid、Flexbox 和媒体播放的浏览器。修改代码后请刷新页面；本项目没有自动热更新。

**视频无法播放或定位异常**

确认 `assets/reference.mp4` 存在。若直接打开文件时遇到浏览器限制，改用本地服务预览；浏览器仍需支持该 MP4 的视频编码。

**提示端口已被占用**

如果已有本项目的预览服务，可以直接访问原地址。也可按「快速开始」中的方法设置其他 `PORT`。
